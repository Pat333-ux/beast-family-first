# Security policy

This repository is a local reference demo and must not be deployed with real case data. It has no authentication, authorization, persistent storage, or production security operations.

Do not report sensitive information in a public issue. For a security concern, use GitHub's private vulnerability reporting for this repository, if enabled. Include the affected version, impact, and a reproducible description without real personal data.

See `docs/safety-and-privacy.md` for the minimum safeguards that must be addressed before production consideration.
